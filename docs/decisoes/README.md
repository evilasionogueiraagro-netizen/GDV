# Decisões

Uma decisão por linha, com data e por quê. Só o estado atual: quando uma decisão muda, edite a linha e a data (o
vai e volta fica no git, não aqui). O que ainda não foi decidido fica em **Em aberto**, no fim do arquivo do tema.

| Tema | Situação | Arquivo |
|---|---|---|
| Controle de acesso (login, código, permissões) | decidido, a implementar | [acesso.md](acesso.md) |
| Outros temas (TF e BVA, PCE, convênio, relatórios, VIGIFITO) | decididos | [anteriores.md](anteriores.md) |

Tema novo: crie `<tema>.md` com a tabela abaixo e uma linha aqui.

```
| Data | Decisão | Por quê |
|---|---|---|
```
